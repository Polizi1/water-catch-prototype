# Water Catch | charity: water

An interactive game built in React, TypeScript, and Vite. Catch clean water droplets to help fund clean water initiatives worldwide while avoiding hazardous polluted drops.

## Features

- **Core Gameplay**: Catch blue droplets (+10 points) with the charity: water jerry can basket. Avoid polluted hazard droplets (-1 life).
- **Controls**: Smooth mouse/pointer tracking and ArrowLeft / ArrowRight keyboard navigation.
- **Winning Condition**: Collect 100 points within the 30-second time limit to trigger the celebratory confetti explosion.
- **charity: water Visual Design**: Faithful recreation of the brand palette (`#FFC907`, `#003366`, `#77A8BB`, `#FFF7E1`), mountains, clouds, and water backdrop.
- **HUD & Status**: Live score tracker, 30s countdown timer, 3-heart health system, progress bar, and feedback notifications.
- **Responsive Layout**: Designed for seamless play across mobile, tablet, and desktop viewports.

## Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler**: Vite
- **Styling**: CSS with charity: water brand tokens

## Development

```bash
npm install

```

Build for production:
